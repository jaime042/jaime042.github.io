Política de privacidad

Dosis Mental Studio · Última actualización: 4 de octubre de 2026

Quién es el responsable

Dosis Mental Studio es una herramienta privada del creador del canal de YouTube Dosis Mental (@DosisMental2). Contacto: superjaime42@gmail.com.

Qué datos usa la aplicación

La aplicación se conecta a la API de datos de YouTube (YouTube Data API v3) únicamente con la cuenta del propio canal Dosis Mental y solo para:

  • subir los vídeos que produce el propio canal;
  • poner a esos vídeos su título, descripción, etiquetas, miniatura, categoría y fecha de publicación;
  • consultar el estado de esos vídeos (procesado, programado o publicado).

No lee, guarda ni comparte datos de espectadores, comentarios, suscriptores ni de ninguna otra cuenta de Google.

Cómo se guardan

El permiso de acceso que concede Google (token OAuth) se guarda solo en el ordenador del propietario del canal, en un archivo al que únicamente tiene acceso su usuario. No se envía a ningún servidor de terceros ni se vende ni se cede a nadie.

Uso de los servicios de Google

El uso que hace Dosis Mental Studio de la información recibida de las API de Google cumple la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de uso limitado. Al usar los servicios de YouTube se aplican también las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

Cómo retirar el permiso

El acceso se puede revocar en cualquier momento desde la página de permisos de la cuenta de Google. Al revocarlo, el token guardado deja de ser válido y la aplicación ya no puede subir vídeos.

Cambios

Si esta política cambia, se publicará aquí con la nueva fecha de actualización.
